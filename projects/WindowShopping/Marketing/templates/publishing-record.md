# Publishing record

Create one record per live platform placement. File name: `ws-YYYYMM-###-<channel>-publish.md`.

```md
# [Content ID] [Channel] publishing record

- Approval queue reference:
- Operator:
- Scheduled in Buffer at (time zone):
- Planned publish time (time zone):
- Actual publish time (time zone):
- Status: scheduled / published / failed / removed
- Buffer post reference:
- Live permalink:
- Final destination and UTM:
- Final caption checksum or approved-version reference:
- Publishing mode: Automatic / Notify Me
- Native completion required: yes / no
- Native completion owner and deadline:
- Native completion details and time:
- Accessibility verified live: yes / no
- Disclosure verified live: yes / no / not applicable
- Operator verification time:
- Incident or change notes:
```

If a post fails, is changed, or is removed, record what happened and return the item to `review-needed` before attempting a new version.
